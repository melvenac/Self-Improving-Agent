## 5. Answer to D-148

(operator-written from the numbers above)

The design's deterministic outcome rule cannot answer the question: it scores 299's own words (tail, command, code) as FORBID tokens, so the pooled A - B effect of -83.9 points is an artifact of which entry each arm was scored against (Arm B is mostly entry 642, whose REQUIRE tokens file and grep match most next acts), and on the same entry the arms are indistinguishable (A 4.3% [2.7%, 6.9%], B-on-299 4.0% [2.8%, 5.9%]). The entry-299 measure does point to an effect where the injection was warranted: after an injection on a real violation, the next qualifying command read PIPESTATUS in 26 of 31 cases (83.9% [67.4%, 92.9%]) against 2 of 7 without an injection (28.6% [8.2%, 64.1%]), and a session's later injected anchors violate far less often than its first (2.5% vs 15.4%), though the baseline is small and neither comparison is controlled. The trigger's precision on 299 is 6.4% [5.1%, 8.1%] (85% of injections land on commands that already read PIPESTATUS or capture the status elsewhere), so the data names one code change, NOT made here: narrow deriveQuery in open-brain/src/trigger/query.ts so the status-read element fires only on a $? read of a trimmer pipeline, not on a PIPESTATUS read and not on a status captured from another statement.

## 6. Limits

- C3: Arm B's would-have-been entry is scored against the store as snapshotted, not as it stood at fire time.
- C4: Cursor fires (and any session without a Claude Code transcript) have no transcript and are NO_TRANSCRIPT.
- C7: rule 2.2b is token matching. Its tokens are listed in section 3; a common word in an entry's action decides most outcomes.
- Subagent transcripts (in a session's subagents directory) are not read; a subagent's Bash call fires under the parent session and may anchor as NO_ANCHOR or to a nearby main-thread call.
- Next act is the first tool_use after the anchor's tool_result and hook attachment (not merely after the anchor), so calls issued in the same model response as the anchor, which could not have seen the injection, are skipped.
- The 299 classifier counts a grep-as-test read (pipe into grep, then $?) as VIOLATING, by the brief's definition, though grep's own status is sometimes the intended signal.
- The within-session drop is not controlled: the first injection in a session is selected by being first.
